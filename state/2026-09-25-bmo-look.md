## Landmines

- **The greyscale original is gone** (deleted 2026-10-01 at Joe's word;
  `git show 3bf7018:app/fraud-decision-support.html` has it). The BMO copy
  is the only player and the only content.
- **The guidance body is a CSS multi-column box.** A new block type flows
  into the two columns unless it is given `column-span: all` (the brief,
  steps and resources have it). Sections carry `break-inside: avoid` and
  are spaced by `margin-bottom`: a top margin is dropped at the head of the
  second column, so the two columns' first headings would not line up.
- **The page grid's first column is `min(--path-w, half)`**, not `1fr`. The
  smoke's equal-width check at 1280 still holds because 1280 is exactly
  where the two meet.
- **No build step, on purpose.** The copy was assembled once by a scratch
  script (crop the photo, splice in content, copy icons from the design
  system sprite) that was not kept. Edit the HTML directly from here on.
- **The photo is a base64 token** (`--hero-photo`) on one ~55 KB line in
  `:root`. Never Read or Edit the whole file carelessly around it; target
  edits by unique strings. It is `hero-photo.jpg` from
  `bsp-design-system/handoffs/employee-security-hub/bundle/project/assets/`,
  cropped to 1100×524 at JPEG 0.72.
- **The smoke takes ~28s on the copy**, not 5s: Playwright waits for each
  rise animation and hover lift to settle. Not a hang.
- **Playwright is not installed globally on this machine.** The smoke ran
  with `NODE_PATH=C:/dev/repos/sp-traffic-analytics/tools/node_modules`
  (playwright 1.62, whose Chromium is already downloaded).
- **The first paint skips `scrollIntoView`** (`state.ui.intro`), or a short
  screen scrolls the new header out of view on load.
- **Icons are copied symbols** from `bsp-design-system/fluent-basic-icons.svg`,
  referenced as `#ic-fluent-<name>-24-regular`. A name not in the page's
  sprite renders blank; copy the symbol in.
- Hard rules still hold for the copy: 14px floor, no uppercase or
  letter-spacing, no pills, no coloured left borders, placeholder banner,
  tokens only in `:root`.
